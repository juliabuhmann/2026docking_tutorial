Pocketworks

Where does a drug bind, and how would a computer know? Five chapters, every structure a real one from the Protein Data Bank.

Built for the ETH Zürich Bioinformatics Concept Course (Protein Bioinformatics II). Structures come from RCSB PDB; the pocket finders and scores on these pages are simplified teaching versions of the published methods, and the page says so where it matters. Progress is kept in this browser only.

Made with Claude Opus 5.5, an AI model by Anthropic, and only partly reviewed by the course team. Texts, numbers and code may still contain errors: if something looks wrong, please tell us.
